## 📌 **Project Overview**

CodeShelf is a collection of multiple small but useful applications created using **Java**, **JSP**, and **MySQL**.
This project is made for the BCA Semester-5 practical submission and also works as a great learning resource.

It includes tools like:

* ✔ Calculator
* ✔ Drawing Canvas
* ✔ Typing Test
* ✔ Online C Editor
* ✔ IP Address Finder
* ✔ Word Counter
  …and more.

The project shows how to connect Java, JSP, and MySQL together to build simple but fully working web applications.

## 🛠️ **How to Run the Project**

### **1. Install Required Software**

* Java JDK (8 or above)
* Apache Tomcat Server
* MySQL + MySQL Workbench
* VS Code / NetBeans

### **2. Import Database**

* Open **MySQL Workbench**
* Create database:

  ```sql
  CREATE DATABASE csdb;
  ```
* Import the SQL file (users table, etc.)

### **3. Run Project on Tomcat**

* Copy project folder into `webapps/`
* Start Tomcat server
* Open in browser:

  ```
  http://localhost:8080/CodeShelf/
  ```
